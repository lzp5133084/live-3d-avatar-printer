【军哥】"没有显示出来3D头像、图片也没有音效，而且3D打印机豪华一点"（V3 三项问题反馈）。

【AI助手】定位根因并修复，升级为 V3.1：

一、3D头像不显示（双重根因，最优先）
  1. addPrintTask 里只 buildEmboss 生成了 group，却从未 scene.add(grp)，
     stepPrint 仅把 visible 置 true，因此成品永远不进入渲染列表 → 补上 scene.add(grp)；
  2. 浮雕朝向错位：局部 +Z 对应世界 +Y，旧代码把底座整体放在头像面上方，
     头像被底座完全遮住 → 改为 face.position.z = EMB_H0（面在上）、base.position.z = EMB_H0/2（底座在下）；
  3. 像素采样错位：旧代码 getImageData(0,0,64,64) 只读了 128 画布的左上 1/4，
     导致头像严重残缺 → 新增 samplePixels() 先重采样到 96×96 再采样；
  4. 头像加载无超时：图片请求挂起会让 await 永久卡住、队列不进人 →
     新增三级降级链（直连 CORS 2.2s → weserv 代理 2.6s → 本地生成首字头像），保证永不卡队列。

二、没有音效
  1. 旧 beep() 开头 if(!audioCtx) return，而 AudioContext 可能从未创建或处于 suspended 状态；
  2. resumeAudio 只在少数入口调用，且 resume() 是异步的，紧跟着的 beep 仍无声；
  3. 修复：新增 unlockAudio()（播放 1 帧静音 buffer 强制解锁 + suspended 时 resume）；
     全局监听 pointerdown / touchstart / click / keydown 反复解锁；
  4. 音色加强：完成音由单点 sine 0.15 音量改为三音上行和弦 + 高频铃声（音量 0.22~0.30）；
     新增 playStartSound()（机械咔哒噪声 + 起步音），打印开始/完成各有反馈；
  5. 设置面板新增「🔊 试听音效」按钮，一键验证。

三、3D打印机豪华化（整机重建）

    外加发光环、台面网格、品牌铭牌 canvas（"军哥懂保 · 3D PRINT STATION"）；
  · 机架：四立柱（前左/前右/后左/后右，含脚座与金环）+ 顶部固定横梁 + 发光条，
    亚克力侧板（MeshPhysicalMaterial opacity 0.16）、Z 轴丝杠、X 轴导轨；
  · 可动龙门：gantryZ 滑座 + 发光条，打印时沿 Z 轴推进并随进度整体下降；
  · 喷头 nozzle：滑车 + 红色机头 + 金色热端 + 喷嘴锥 + 发光尖端 + 旋转风扇 + 双色线材；
  · 料盘 _spool 缓慢自转、星屑粒子 _dust 上升循环、左侧控制屏 canvas（READY / PRINTING 状态）；
  · 画面调优：exposure 1.15→0.92、聚光灯 1.6→0.45、光晕 .55→.2、床面 metalness .45→.08，
    相机拉近至 (6.2,5.4,8.2)，消除台面过曝导致成品被白光淹没的问题。
